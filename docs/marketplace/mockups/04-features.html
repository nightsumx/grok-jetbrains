Grok Build for JetBrains

Open the agent in the Terminal, inject editor selections into prompts, and share IDE context via a local MCP bridge — open source, Apache-2.0.

⌘ Open Grok Ctrl+Esc

One shortcut opens a dedicated Grok Build terminal tab and runs grok in the project root.

⌘ Send selection ⌥⌘K

Injects file path, line range, and selected body into the prompt — no MCP tool call required for context.

⌘ IDE MCP bridge

Open files, diagnostics, reformat, and diffs. Auto-registers in ~/.grok/config.toml.

⌘ Works with your stack

WebStorm, IntelliJ, PyCharm, GoLand, and more (2024.2+). Requires the Grok Build CLI on the machine.
